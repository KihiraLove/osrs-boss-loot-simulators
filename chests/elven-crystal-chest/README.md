# Elven Crystal Chest

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/chests/elven-crystal-chest/) · [Chest guides](../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Elven_Crystal_Chest)

Uses an enhanced crystal key. Uncut onyx: 1/10,000; each dragonstone armour piece: 1/2,500. These rare outcomes are modeled as mutually exclusive at their published rates.

- Otherwise one 256-ticket reward bundle includes an uncut dragonstone. Shield left half is 1/256 on this ordinary table, or 0.9979/256 per opening.
- The dry calculator tracks the onyx, five armour pieces and shield left half.

# Chest (moon key)

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/chests/moon-key-chest/) · [Chest guides](../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Chest_%28moon_key%29)

Always gives 250 sunfire splinters. Roll an onyx at 1/5,000, then a helmet at 1/500 only if the onyx fails; otherwise roll the 107-ticket main table.

- The effective helmet chance per opening is (4,999/5,000)/500, approximately 1/500.1. Splinters are awarded even when a rare succeeds.
- The dry calculator tracks Uncut onyx and Helmet of the moon.

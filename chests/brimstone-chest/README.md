# Brimstone Chest

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/chests/brimstone-chest/) · [Chest guides](../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Brimstone_chest)

Broken dragon hasta: 1/200. Each of five dusk mystic pieces: 1/1,000. These mutually exclusive rewards replace the ordinary roll.

- Otherwise roll the 60-ticket main table, including three fish tickets. Fishing level affects fish type.
- Dry inputs count hasta and mystic pieces. See the [shared chest notes](../README.md) for fish estimates and quantity rounding.

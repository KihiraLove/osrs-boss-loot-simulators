# Phosani's Nightmare

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/phosani/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Phosani%27s_Nightmare)

Phosani's Nightmare solo table only. The staff/armour/mace table rolls at 1/140 and the orb table independently at 3/1,600; both can succeed on one kill.

- The dry calculator combines those tables for signature totals, with pet, egg and jar shown separately.
- Slepey tablet is guaranteed by the 25th simulated kill if none has dropped. Sessions start at zero KC. Rounded common weights are normalized; Elite Combat Achievements improve clues.

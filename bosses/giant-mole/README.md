# Giant Mole

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/giant-mole/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Giant_Mole)

Each kill gives big bones, a mole claw, 1–3 mole skins and one ordinary loot roll.

- Immaculate mole skin rolls separately at 1/50; Baby Mole is 1/3,000. Dry odds cover both and their combined count.
- Elite Combat Achievements improve elite clues. Ring of wealth affects rare and gem tables. The Falador Diary changes noting, so it does not change simulated quantities.

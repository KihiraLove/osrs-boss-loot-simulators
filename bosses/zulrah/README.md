# Zulrah

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/zulrah/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Zulrah)

Each kill gives Zulrah scales and two independent rolls on the 249-ticket ordinary table. Unique-table outcomes can appear twice in one kill.

- Mutagens replace the flax outcome. Pet, jar and clue chances are separate from the two main rolls.
- Dry odds retain the correct number of trials for each reward. Elite Combat Achievements improve clues; Ring of wealth affects rare-table loot.

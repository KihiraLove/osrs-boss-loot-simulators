# Royal Titans

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/royal-titans/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/The_Royal_Titans)

Enter Solo Branda, Solo Eldric, Duo Branda and Duo Eldric counts. Loot and dry odds combine all four; duo rewards use 50% contribution.

- Choose Loot, Sacrifice or Take pages using the reward radios. Sacrifice doubles pet odds while forfeiting primary rewards; pages replace primary loot. Clues remain available.
- Both prayer scrolls remain repeatable. Published marginal primary chances are modeled as mutually exclusive because the internal roll order is undocumented. The combined plan is capped at 1,000,000 kills.

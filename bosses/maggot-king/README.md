# Maggot King

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/maggot-king/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Maggot_king)

Enter Open-stomach and Take-eggs counts together. Weapon uniques use only Open-stomach kills; the pet result combines both choices.

- Pet chances are 1/3,500 for Open-stomach and about 1/1,502.4 for Take-eggs, assuming every egg is popped. Loot records eggs obtained before popping.
- The unreported split between nothing and supplies on non-egg outcomes is omitted rather than estimated. Elite Combat Achievements improve clues.

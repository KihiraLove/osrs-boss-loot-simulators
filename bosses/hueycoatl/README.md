# The Hueycoatl

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/hueycoatl/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/The_Hueycoatl)

Enter solo, duo and trio kills together. The contribution assumptions are 100%, 50% and one third; dry odds combine their different rates.

- Hueycoatl hides arrive in batches of three, so enter actual hide quantities. The moon-key tooth half is approximately 1/75 per participant.
- Hard Combat Achievements improve clues. Group MVP bones are omitted because contribution alone does not identify the MVP. No prior collection is assumed.

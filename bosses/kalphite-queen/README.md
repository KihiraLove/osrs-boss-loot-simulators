# Kalphite Queen

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/kalphite-queen/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Kalphite_Queen)

Each kill gives one ordinary loot roll and one consumables roll, with separate collection-log reward rolls.

- Kq head and dragon chainbody: 1/128 each; dragon 2h sword: 1/256; dragon pickaxe: 1/400; jar: 1/2,000; pet: 1/3,000. The dry total allows several rares on one kill.
- The lifetime-KC tattered head guarantee is excluded. Elite Combat Achievements and Ring of wealth affect simulated loot.

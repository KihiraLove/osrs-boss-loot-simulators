# Venenatis &amp; Spindel

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/venenatis-spindel/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Venenatis) · [Wiki source 2](https://oldschool.runescape.wiki/w/Spindel)

Enter Venenatis and Spindel kills separately to combine loot and dry results.

- Each boss retains its own rare and pet probabilities. Dry odds combine both distributions instead of averaging their rates.
- Both encounters use solo/full-credit rewards. Ring of wealth (i) affects Wilderness clue rolls and rare-table loot.

# Kraken

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/kraken/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Kraken)

Enter completed Kraken boss kills. Trident of the seas (full): 1/512; Kraken tentacle: 1/400.

- The ordinary table and tertiary rewards are simulated separately. Jar of dirt and the pet are included in dry odds.
- Elite Combat Achievements improve elite clues. Ring of wealth affects rare-table rewards. Existing clue ownership is not tracked.

# Shellbane Gryphon

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/shellbane-gryphon/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Shellbane_gryphon)

Each kill gives big bones, gryphon feathers and two separate ordinary loot rolls. Belle's folly uses the increased July 2026 rate of 1/75.

- Jar of Feathers: 1/2,000; Gull: 1/3,000. Dry odds combine the weapon roll with these separate tertiary rewards.
- Elite Combat Achievements improve normal elite clues. Ring of wealth affects rare-table rewards.

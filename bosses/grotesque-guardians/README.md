# Grotesque Guardians

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/grotesque-guardians/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Grotesque_Guardians)

Enter completed encounters. Each gives two independent main loot rolls, with separate pet, jar and clue chances.

- The dry calculator uses two trials per kill for main-table uniques and adamant boots, and one for tertiary rewards.
- Elite Combat Achievements improve clues. Noon is 1/3,000 and Jar of stone is 1/5,000.

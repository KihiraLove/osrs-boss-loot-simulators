# The Gauntlet

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/gauntlet/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Reward_Chest_(The_Gauntlet))

Enter normal and Corrupted Gauntlet completions separately. The simulator combines both reward tables in one inventory.

- Dry odds combine the distinct normal and corrupted chances for crystal weapon, armour and enhanced seeds, plus Youngllef.
- Only successful completions are modeled. The combined result uses both distributions, not one averaged drop rate.

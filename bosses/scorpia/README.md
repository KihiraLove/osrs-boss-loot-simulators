# Scorpia

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/scorpia/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Scorpia)

Enter completed Scorpia kills. The odium shard and malediction shard are each 1/256, with a separate pet roll.

- Dry odds combine the exclusive shard outcomes with independent pet drops.
- Ring of wealth (i) doubles Wilderness clue chances. Hard Combat Achievements also improve hard clues.

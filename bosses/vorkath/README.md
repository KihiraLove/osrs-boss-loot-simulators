# Vorkath

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/vorkath/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Vorkath)

Enter completed post-quest kills. Each kill gives superior dragon bones, blue dragonhide and two ordinary loot rolls.

- Vorkath's head is guaranteed on the 50th simulated kill if none has appeared. The simulator begins at zero KC. Visages, jar, pet and other tertiary rewards retain their separate rolls.
- Dry odds include the guaranteed 50th-kill head and repeatable rares. Elite Combat Achievements improve elite clues; Ring of wealth affects rare-table loot.

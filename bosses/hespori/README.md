# Hespori

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/hespori/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Hespori)

Enter completed Hespori kills and Farming level. Each kill gives an anima-seed reward and either ordinary seeds or a bottomless compost bucket.

- Bottomless compost bucket: 1/35. Tangleroot uses Farming-level-dependent odds. The dry calculator covers both rewards.
- The farmer's outfit changes the displayed Farming experience. The page uses the bottomless compost bucket as its icon.

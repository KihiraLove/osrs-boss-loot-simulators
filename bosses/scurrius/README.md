# Scurrius

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/scurrius/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Scurrius)

Solo kills only. Each kill gives big bones, raw rat meat and one ordinary loot roll. Scurrius' spine is 1/33; Scurry is 1/3,000.

- Spine and pet roll independently. Their combined dry result allows both on one kill.
- Medium Combat Achievements improve medium clues.

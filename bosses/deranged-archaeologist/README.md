# Deranged Archaeologist

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/deranged-archaeologist/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Deranged_archaeologist)

Enter completed kills. The Steel ring occupies 3/131 main-table tickets and replaces the ordinary reward.

- Numulite, fossils and elite clues have separate rolls. Rare, gem and seed subtables use normalized published weights.
- The dry calculator tracks Steel rings. Elite Combat Achievements improve clues; Ring of wealth affects rare-table rewards.

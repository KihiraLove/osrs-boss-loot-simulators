# Amoxliatl

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/amoxliatl/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Amoxliatl)

Enter completed post-quest kills. Each kill gives frozen tears and two ordinary loot rolls.

- Pendant of ates: 1/25; Glacial temotli: 1/100; Moxi: 1/3,000; moon-key tooth half: 1/125. These roll independently.
- Dry odds cover those four rewards. The combined signature result includes pendant, temotli and pet. Elite Combat Achievements and Ring of wealth affect simulated loot.

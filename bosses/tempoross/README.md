# Tempoross

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/tempoross/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Reward_pool)

Enter reward permits (pool searches), not completed games, and base Fishing level when claiming them.

- Each permit awards one outcome. Published rare chances take priority; if none succeeds, common rewards use relative weights. This approximation reduces common frequencies by 201/8,000.
- Barrel and tackle box start unowned and can drop once; later hits become 25 soaked pages. Dry odds account for this cap. Caskets stay unopened; soaked-page quantities are excluded from dry inputs.

# General Graardor

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/general-graardor/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/General_Graardor) · [Wiki source 2](https://oldschool.runescape.wiki/w/Sergeant_Strongstack) · [Wiki source 3](https://oldschool.runescape.wiki/w/Sergeant_Steelwill) · [Wiki source 4](https://oldschool.runescape.wiki/w/Sergeant_Grimspike)

Each entered kill includes General Graardor and the three guards. Loot appears in four source panels.

- Dry odds combine boss and guard chances for each unique. More than one copy can arrive during the same room clear.
- Hard and Elite Combat Achievements improve the matching clues. Ring of wealth affects rare-table rewards.

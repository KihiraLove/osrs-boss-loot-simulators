# Moons of Peril

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/moons-of-peril/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Moons_of_Peril)

Enter Lunar Chests with all three Moons defeated. Each Moon has an independent 1/56 unique roll.

- Each four-piece set has duplicate protection until complete. The simulator and dry calculator start with an empty collection and track this protection per set.
- Any unique skips the entire common-loot table; otherwise the chest gives six ordinary rolls. Dry item odds account for changing selection pools instead of treating each piece as a constant 1/224 roll.

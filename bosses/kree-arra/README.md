# Kree'arra

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/kree-arra/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/General_Kree'arra) · [Wiki source 2](https://oldschool.runescape.wiki/w/Flight_Kilisa) · [Wiki source 3](https://oldschool.runescape.wiki/w/Wingman_Skree) · [Wiki source 4](https://oldschool.runescape.wiki/w/Flockleader_Geerin)

Each entered kill includes Kree'arra and all three bodyguards. Their loot appears in separate panels.

- Dry odds combine boss and bodyguard probabilities, preserving the possibility of multiple rewards during one room clear.
- Hard and Elite Combat Achievements improve clues. Ring of wealth affects rare-table rewards.

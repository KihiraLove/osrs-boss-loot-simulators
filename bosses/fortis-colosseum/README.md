# Fortis Colosseum

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/fortis-colosseum/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Rewards_Chest_%28Fortis_Colosseum%29)

Enter individual completions for Waves 1–12. Each field rolls only that wave; results combine all entered rewards. A complete run requires one completion in every wave field.

- Wave 12 awards a quiver. Choose Keep, Exchange for splinters or Gamble for the pet. Gambling stops after the simulated pet is obtained.
- Armour protection carries across waves. Dry inputs count echo reward rolls, not crystal quantities. Pet dry odds cover chest rolls only, excluding optional quiver gambles.

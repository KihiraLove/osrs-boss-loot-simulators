# Cerberus

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/cerberus/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Cerberus)

Enter completed Cerberus kills. Primordial, Pegasian and Eternal crystals and the Smouldering stone are each 1/520; their combined roll is 1/130.

- Jar of souls: 1/2,000; Hellpuppy: 1/3,000. These roll separately from the crystal/stone table.
- The published main-table weights already total a full table, so its listed 3/130 rare-table access is modeled as an additional roll. This is an approximation. Elite Combat Achievements and Ring of wealth are supported.

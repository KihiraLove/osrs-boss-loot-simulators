# Abyssal Sire

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/sire/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Abyssal_Sire) · [Wiki source 2](https://oldschool.runescape.wiki/w/Unsired)

Enter Abyssal Sire kills. Unsired is a 1/100 pre-roll that replaces normal loot; every simulated Unsired is immediately offered to the Font.

- Font rewards appear separately. Bludgeon pieces avoid duplicates until a set is complete, and the pet is awarded at most once.
- Dry inputs separate kills/Unsireds from Font rewards. Font probabilities use Unsired count rather than kill count. Elite Combat Achievements and Ring of wealth affect boss loot.

# King Black Dragon

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/king-black-dragon/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/King_Black_Dragon)

Enter completed kills. The dragon pickaxe pre-roll can replace normal loot; visage, Kbd heads and the pet roll independently.

- Dry odds combine those independent sources and allow more than one rare per kill.
- Monkey Madness II controls the dragon-javelin-head outcome. Elite Combat Achievements improve clues; Ring of wealth affects rare-table loot.

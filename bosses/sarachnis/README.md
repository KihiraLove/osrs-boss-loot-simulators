# Sarachnis

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/sarachnis/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Sarachnis)

Enter completed kills. Sarachnis cudgel is a 1/384 main-table outcome. Jar of eyes, Sraracha and the giant egg sac have separate rolls.

- Ordinary loot includes herb and rare-table branches. Dry odds preserve shared main outcomes and independent tertiary rewards.
- Elite Combat Achievements improve clues. Ring of wealth affects rare and gem-table loot.

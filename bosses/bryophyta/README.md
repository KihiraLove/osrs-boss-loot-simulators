# Bryophyta

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/bryophyta/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Bryophyta) · [Wiki source 2](https://oldschool.runescape.wiki/w/Chest_(Bryophyta%27s_lair))

Boss loot and chest loot are separate. Enter completed kills and how many were on task; task kills double the boss mossy-key chance from 1/16 to 1/8.

- Bryophyta's essence comes from chests at 1/118, never directly from kills. Pre-obtained keys open one chest per kill; boss-obtained keys and chest-dropped keys fund additional openings.
- The dry calculator uses chest openings. Members and Free-to-play tables are supported; automatic key chains stop at 1,000,000 openings.

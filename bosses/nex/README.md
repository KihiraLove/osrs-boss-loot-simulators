# Nex

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/nex/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Nex) · [Wiki source 2](https://oldschool.runescape.wiki/w/Nihil_shard)

OSRS Nex only. Enter nihil shards received from Nex itself, excluding minions, trades and purchases.

- Shards estimate contribution-equivalent kills at about 8.4755 shards per full kill. Rare counts use a Poisson approximation; the shard input cannot recover actual KC, contribution or MVP bonuses.
- The six OSRS unique rewards and Nexling use that estimated exposure. The combined unique card excludes the pet. Ordinary loot has illustrative weights because exact published weights are incomplete; it is not an exact loot reconstruction.

# Duke Sucellus

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/duke-sucellus/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Duke_Sucellus)

Enter normal Duke Sucellus kills. Perfect improves ordinary quantities without changing unique or pet chances.

- Magus vestige arrives on every third vestige-table hit. Dry odds use floor(Binomial(kills, 1/240) / 3), starting with zero hidden progress.
- Tablet pity uses the published base rate; first-quartz scaling is approximated linearly. Both are excluded from dry inputs. The 22 unspecified ordinary-table tickets remain empty.

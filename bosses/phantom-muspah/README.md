# Phantom Muspah

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/phantom-muspah/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Phantom_Muspah)

Enter completed kills. A Venator shard has a 1/100 chance and prevents all other loot on that kill.

- Non-shard kills give ancient essence, a frozen cache or an ancient icon, followed by ordinary loot or bundled supplies. Muphin uses 0.99 × 1/2,500 per entered kill.
- Dry odds cover shard, cache, icon and pet. Hard/Elite Combat Achievements improve clues; Ring of wealth affects rare-table rewards.

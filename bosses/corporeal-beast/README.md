# Corporeal Beast

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/bosses/corporeal-beast/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Corporeal_Beast)

This calculator uses solo kills only. Each kill has an ordinary loot roll and an independent sigil roll: Elysian 1/4,095, Spectral and Arcane 1/1,365 each.

- Jar of spirits: 1/1,000; Pet dark core: 1/5,000. Dry totals combine the exclusive sigil roll with independent rewards.
- Gem-table entry gives ten rolls. Ring of wealth removes empty outcomes; the Legends' Quest setting controls mega-rare rewards. Elite Combat Achievements improve clues.

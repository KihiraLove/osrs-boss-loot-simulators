# Hard Clue Caskets

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/treasure-trails/hard/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Reward_casket_%28hard%29)

Enter opened caskets. Each gives 4–6 equally likely reward rolls; duplicates can occur within one casket.

- Includes all standard loot, 134 hard collection-log items, 24 gilded/3rd Age items, shared clue rewards and the separate 1/15 master clue roll per casket.
- Dry odds track all 158 collection-log items and their combined total. Master clues are calculated separately; shared rewards appear in simulated loot.
- Uses exact table probabilities before Wiki display rounding. Super attack, strength and defence potions drop together.
- Assumes master clue rewards can be claimed each time. Milestone scroll cases and the Uri transform emote are excluded.
- Supports up to 1,000,000 caskets. Images are local. Dry odds retain the random roll count and trim negligible probability tails for large inputs.

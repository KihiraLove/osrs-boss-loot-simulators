# Medium Clue Caskets

[Open simulator](https://kihiralove.github.io/osrs-boss-loot-simulators/treasure-trails/medium/) · [All simulators](../../README.md) · [OSRS Wiki](https://oldschool.runescape.wiki/w/Reward_casket_%28medium%29)

Enter opened caskets. Each gives 3–5 equally likely reward rolls; duplicates can occur within one casket.

- Includes all standard rewards, 115 medium collection-log items, shared clue rewards and the separate 1/30 master clue roll per casket.
- Dry odds track each medium collection-log item and their combined total. Master clues are calculated separately; shared rewards appear in simulated loot.
- Uses standard rewards outside Entrana and assumes master clue rewards can be claimed each time. Milestone scroll cases and the clueless scroll are excluded.
- Supports up to 1,000,000 caskets. Images are local. Dry odds retain the random roll count and trim negligible probability tails for large inputs.
